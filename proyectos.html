Proyecto Estelar

Nexo

Cliente de escritorio estudiantil unificado con IA local. Consolida campus virtual, correo institucional, agenda académica y asistente IA en una sola interfaz nativa, sin depender de la nube para procesamiento inteligente.

Ver Documentación Repositorio GitHub Descargar PDF
Rust Python Ollama Tauri WebSocket SQLite OAuth 2.0 REST API

Características Principales

IA Local con Ollama

Asistente académico que corre modelos LLM directamente en el dispositivo. Sin latencia de nube, con privacidad total.

Campus Virtual Unificado

Integración con múltiples plataformas universitarias (Moodle, Blackboard) mediante adaptadores modulares.

Agenda Académica Inteligente

Sincronización automática de fechas de entrega, exámenes y horarios con alertas predictivas.

Correo Institucional Integrado

Cliente con soporte IMAP/SMTP, categorización automática con IA y resumen de hilos de conversación.

Rendimiento Nativo

Backend en Rust para operaciones de alta performance con uso de memoria ultra-bajo vs Electron.

Privacidad por Diseño

Datos en SQLite cifrado localmente. La IA nunca envía prompts a servidores externos.
